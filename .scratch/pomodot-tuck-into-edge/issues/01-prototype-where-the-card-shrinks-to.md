# 01 — การ์ดหุบเข้าตรงไหน ลองลากดูเอง

**Parent:** [map](../map.md)
**Type:** `wayfinder:prototype` (HITL)
**Assignee:** teppasit (agent session)
**Blocked by:** —
**Status:** closed

## Question

ทำ prototype HTML (ผ่าน `/prototype`) เป็นจอจำลองที่มี menu bar กับ Dock มีแคปซูล 128×38 และการ์ด 284×200 ที่คลิกขยาย ลาก และหุบได้ (ปุ่ม "หุบ" แทนการเอาเมาส์ออก 0.5 วิ) ใช้กฎที่ตัดสินตอน charting แล้วให้ผู้ใช้ลองลากดูว่าตรงกับที่คิดไว้ไหมในทุกกรณี:

1. การ์ดกลางจอ → หุบเข้ากลาง (เหมือนเดิม)
2. ลากการ์ดไปชนมุมขวาล่าง (ภาพของผู้ใช้) → หุบเข้ามุมขวาล่าง; มุมอื่นอีกสามมุมเหมือนกัน
3. ชนแค่ขอบเดียว เช่นขอบขวาแต่อยู่กลางแนวตั้ง → หุบเข้าขอบขวา ตรงกลางแนวตั้งของการ์ด
4. เปิดการ์ดจากแคปซูลที่อยู่มุม (การ์ดชิดมุม) แล้วลากออกมากลางจอ → หุบเข้ากลาง ไม่ใช่มุมของการ์ด
5. ลากการ์ดไปใกล้ขอบแต่ไม่ชน → หุบเข้ากลาง (ผู้ใช้รู้สึกโอเคไหม)
6. หุบแล้วคลิกขยายอีกครั้ง → การ์ดกลับมาที่เดิม
7. ระหว่างลาก การ์ดไม่กระตุกหรือกระโดดเมื่อชนขอบ และหุบแล้ว animation ดูหดเข้ามุม/ขอบนั้นจริง

ผลที่ต้องได้: ผู้ใช้ยืนยันกฎ (หรือแก้) ทุกข้อข้างบน — เป็นข้อมูลให้ตั๋ว "เขียนหัวข้อหุบเข้าขอบใน spec และหั่นตั๋ว" เขียน spec ได้เลย

## Resolution

ผู้ใช้เลือก **แบบ C: หุบเข้าขอบ/มุมที่การ์ดอยู่ใกล้** (2026-10-17) — "ใช่เลย แบบที่ต้องการ"

- **แบบ B (ต้องชนขอบจริง) ไม่ใช่:** ผู้ใช้ส่งภาพการ์ดที่ห่างขอบซ้าย/ขวาและขอบล่างราว 40 pt แล้วบอกว่าต้องหุบเข้ามุมซ้ายล่าง/ขวาล่าง "ไม่ต้องชนขอบก็เข้ามุม"
- **กฎ (แบบ C):** ปล่อยเมาส์หลังลากการ์ด การ์ดอยู่ที่เดิม แต่จุดที่แคปซูลจะหุบเข้าคำนวณจากระยะการ์ดถึงขอบพื้นที่ใช้งาน (`visibleFrame`) ของจอ
  - แนวนอน: ห่างขอบซ้าย **น้อยกว่า 78 pt** → หุบชิดซ้ายของการ์ด; ห่างขอบขวาน้อยกว่า 78 pt → ชิดขวา; ไม่งั้นกลาง
  - แนวตั้ง: ห่างขอบบน/ล่าง **น้อยกว่า 81 pt** → ชิดบน/ล่างของการ์ด; ไม่งั้นกลาง
  - ใกล้ทั้งสองแนว = มุม, ไม่ใกล้แนวไหน = กลางการ์ด
  - 78 = (284 − 128) / 2 และ 81 = (200 − 38) / 2 คือ**ระยะเดียวกับการขยายใกล้ขอบ**ที่มีอยู่ (แคปซูลที่หุบเข้าขอบจะขยายออกจากขอบเดิม) ผลคือ **หุบแล้วขยายอีกครั้ง การ์ดกลับมาที่เดิมเป๊ะ**
- ข้อ 1–3, 5 ผู้ใช้ลองเองผ่าน; ข้อ 6 (ขยายอีกครั้งแล้วอยู่ที่เดิม) agent ลองใน prototype ผ่านทั้งมุมซ้ายล่าง ขวาล่าง และกลาง; ข้อ 4 (เปิดจากมุมแล้วลากมากลาง → หุบเข้ากลาง) เป็นผลตรงของกฎ; ข้อ 7 (กระตุก/animation) ตรวจในแอพจริงตอนทดสอบด้วยมือ
- การ์ดไม่ขยับตอนปล่อย — ไม่ใช่การดูดการ์ดเข้าขอบ เปลี่ยนแค่จุดที่แคปซูลอยู่ในการ์ด
