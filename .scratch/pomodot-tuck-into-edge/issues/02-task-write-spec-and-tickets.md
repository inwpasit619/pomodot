**Parent:** [map](../map.md)

## Question

เขียนกฎที่ผู้ใช้ยืนยันในตั๋ว 01 ลง [spec](../../pomodoro-v1/spec.md) เป็นหัวข้อใหม่ต่อจาก M6 แล้วสร้างตั๋ว implement ใน `.scratch/pomodot-build/issues/` (ต่อจากเลข 28) — นี่คือปลายทางของ map

ต้องมีใน spec:

- กฎหุบเข้าขอบ/มุม/กลาง และขีดฆ่าข้อ M2 ที่ขัดกัน ("เลือกทิศตอนเริ่มขยาย แล้วไม่เปลี่ยนจนกว่าจะหุบ") พร้อมเหตุผลเดิมที่ยังต้องรักษา: การ์ดห้ามกระโดดหนีเมาส์
- เรื่องเทคนิคที่ agent ตัดสินแล้วอธิบายเป็นภาษาคน: เลือกทิศใหม่**ตอนปล่อยเมาส์หลังลาก** (การ์ดไม่ขยับ เปลี่ยนแค่ว่าแคปซูลอยู่ตรงไหนในการ์ด และตำแหน่งที่จำไว้ใน `state.json` ถูกตั้งแต่ตอนนั้น) หรือ**ตอนหุบ** (ครอบคลุมการ์ดที่ถูกย้ายโดยไม่ได้ลากด้วย) — ดูหมอกใน map
- animation ตอนหุบหดเข้าทิศใหม่ (ไม่ใช่ทิศตอนขยาย)
- test ของ Core seam 4 แบบ Given/When/Then ด้วยตัวเลขจริง (จอ (0, 0)–(1440, 875), แคปซูล 128×38, การ์ด 284×200) ครบกรณีในตั๋ว 01 รวมถึงขยาย→หุบ→ขยายแล้วการ์ดอยู่ที่เดิม
- checklist ทดสอบด้วยมือ (ลากจริงด้วยเมาส์ ทั้งสี่มุม ขอบเดียว และสองจอถ้ามี)
- เลขเวอร์ชัน: agent เสนอ (0.10.1 หรือ 0.11.0 ตามกติกา version ใน spec) แล้วให้ผู้ใช้อนุมัติ และหัวข้อ release notes
