## Question

**ผู้ใช้อยากได้ UI แบบ modern** — ให้ prototype ช่วยหาว่า "modern" หมายถึงอะไร (เช่น วัสดุโปร่งแสง/blur แบบ macOS, มุมโค้ง, ตัวเลขใหญ่, animation นุ่มๆ) ทำมาให้เลือกหลายแบบ แล้วใช้สไตล์ที่ได้กับ Settings และสถิติด้วย

หน้าต่างลอยควรหน้าตาเป็นยังไง ทำ mock แบบหยาบๆ (HTML ผ่าน `/prototype` ไม่ต้องใช้ Xcode) ให้ผู้ใช้ดูแล้วเลือก

- ขนาด (เล็กแค่ไหน), รูปทรง (แคปซูล / สี่เหลี่ยมมุมมน / วงกลม), ความโปร่งใส
- โชว์อะไรบ้าง: เวลา, ชื่อช่วง (Focus/Break), รอบที่เท่าไหร่, ปุ่มควบคุม (โชว์ตลอดหรือโชว์ตอน hover)
- ช่วง focus กับช่วง break ใช้สีต่างกันไหม
- ตำแหน่งเริ่มต้นบนจอ, ลากย้ายได้และจำตำแหน่งไว้, มีโหมดย่อ/ขยายไหม
- light/dark mode
- (ส่งต่อมาจากตั๋ว "กติกาของ timer") มีวงแหวน/แถบ progress คู่กับ `mm:ss` ไหม, หน้าตาตอน Pause, **Expected finish** ของ Phase และของ Cycle วางตรงไหน และโชว์ตลอดหรือโชว์ตอน hover, ปุ่มบนหน้าต่างลอยมีแค่ ▶︎/⏸, Reset, Skip (ส่วน New Cycle อยู่ในเมนู)
- (ส่งต่อมาจากตั๋ว "menu bar กับหน้าต่างลอย เกี่ยวกันยังไง") มี**ปุ่มซ่อน**บน Floating Window ด้วย (ปิด = ซ่อน ไม่ใช่ออกจากแอพ) ไม่มีปุ่ม Quit, ปุ่มหมุด always-on-top หรือเมนูคลิกขวา ข้อความเป็นภาษาอังกฤษ
- (ส่งต่อมาจากตั๋ว "แจ้งเตือนกับเสียงตอนหมดเวลา ทำงานยังไง") Floating Window ไม่กะพริบเพื่อแจ้งเตือน แต่จะมี animation เล็กๆ ตอนเปลี่ยน Phase ไหม และส่วน Notifications & Sound ใน Settings (สวิตช์ notification, dropdown เสียง 2 ช่อง, บรรทัดเตือนตอนระบบปิดสิทธิ์) ต้องเข้ากับสไตล์ modern ด้วย
- (ส่งต่อมาจากตั๋ว "สถิติ/ประวัติ นับอะไร แสดงยังไง") หน้าต่าง Statistics มีการ์ด 3 ใบ (Today / This Week / All Time), กราฟแท่ง 7 วันล่าสุด และปุ่ม `Clear History…` ให้ทำ mock ด้วยสไตล์ modern ที่เลือก

## Answer

(ปิดเมื่อ 2026-10-15 ผู้ใช้ลองเล่น prototype แล้วเลือก ตัว prototype เก็บไว้ที่ branch `prototype/floating-window-look` ในนั้นมี 7 แบบ (A–G) ให้กลับไปเปิดดูได้ แบบที่ชนะคือ **G** ศัพท์ **Floating Window** ใน `CONTEXT.md` เพิ่มเรื่อง 2 สถานะแล้ว)

**"modern" แปลว่าอะไร**
- พื้น**กระจกโปร่งแสงเบลอ** (material ของ macOS), มุมโค้งมน, ตัวเลขใหญ่แบบ SF Rounded ที่ความกว้างตัวเลขเท่ากันทุกตัว (ตัวเลขไม่ขยับไปมาตอนนับ), animation นุ่มๆ, สีประจำแต่ละ Phase
- ใช้ฟอนต์ระบบ (SF) ทั้งแอพ ไม่ลงฟอนต์เพิ่ม

**Floating Window = แบบ G "Island → Card (adaptive)"** มี 2 สถานะ

```
ย่อ (ปกติ)                ขยาย (ชี้ค้าง / คลิก)
( ● 24:12 )        →     ┌──────────────────────────────┐
                         │ [● Focus] ●○○○ 2/4       [×] │
                         │ 24:12  PAUSED                │
                         │ ━━━━━━━━━━━━━━━━━━━━━━━━──   │
                         │ Phase ends     Cycle ends    │
                         │ 3:17 PM        4:32 PM       │
                         │ [ ▶︎ Resume ]   [↺]   [⏭]    │
                         └──────────────────────────────┘
```

- **ตอนย่อ** (ประมาณ 128×38 pt แคปซูล): จุดสีของ Phase + `mm:ss` เท่านั้น ตอน Pause มีคำว่า `PAUSED` ตอนรอกด ▶︎ มีคำว่า `READY` ตอนกำลังเดินจุดจะเรืองแสงเบาๆ
- **ตอนขยาย** (ประมาณ 284×200 pt การ์ดมุมโค้ง): ป้าย Phase, จุดบอกความคืบหน้าใน Cycle + `2/4`, ปุ่มซ่อน `×` มุมขวาบน, เวลาตัวใหญ่ + `PAUSED`/`READY`, แถบเวลาที่เหลือ, **Expected finish ของ Phase และของ Cycle** (โชว์เฉพาะตอนขยาย ถ้าซ่อนหน้าต่างอยู่ก็ดูได้จากเมนู), ปุ่มใหญ่ `Start` / `Pause` / `Resume` สีของ Phase + ปุ่ม Reset และ Skip
- ปุ่มบนหน้าต่างมีแค่ Start/Pause/Resume, Reset, Skip, ซ่อน ตามที่ตกลงไว้ (ไม่มี New Cycle, Quit, หมุด, เมนูคลิกขวา)
- **ตอน Pause:** ตัวเลขค่อยๆ จางลงแล้วเข้มขึ้น (เหมือนหายใจ) + คำว่า `PAUSED`
- **สีต่อ Phase:** Focus = แดงมะเขือเทศ, Short Break = เขียว, Long Break = น้ำเงิน (ใน prototype ใช้ #F0524F / #2FBF5B / #0A84FF) ใช้กับจุด, ป้าย, แถบ และปุ่มหลัก

**ชี้ / คลิก / ลาก**
- เอาเมาส์**ชี้ค้าง 0.3 วินาที**แล้วขยาย ถ้าเมาส์แค่ผ่านไปจะไม่ขยาย เอาเมาส์ออกแล้ว**รอ 0.5 วินาที**ค่อยหุบ ถ้าเมาส์กลับมาทันจะไม่หุบ
- **คลิกแคปซูล (ไม่ลาก) = ขยายทันที**
- **กดค้างแล้วลากแคปซูลได้โดยไม่ขยาย** ระหว่างลากจะไม่ขยายเลย และปล่อยแล้วก็ยังไม่ขยาย จนกว่าเมาส์จะออกไปแล้วกลับมาชี้ใหม่ ตอนขยายอยู่ลากการ์ดได้ถ้ากดที่พื้นที่ไม่ใช่ปุ่ม
- ลากได้ถึงขอบจอทุกด้าน แต่ลากออกนอกจอไม่ได้
- การขยายใช้ animation ประมาณ 0.35 วินาที

**การขยายใกล้ขอบจอ** (แคปซูลอยู่ที่เดิมเสมอ การ์ดขยายไปทางที่มีที่ว่าง)
- แคปซูลอยู่ครึ่งบนของจอ การ์ดขยาย**ลงล่าง** ถ้าอยู่ครึ่งล่าง การ์ดขยาย**ขึ้นบน**
- ปกติการ์ดขยายออกเท่ากันทั้งซ้ายและขวา ถ้าจะทะลุขอบขวา การ์ดจะชิดขวาแล้วขยายไปทางซ้ายแทน ขอบซ้ายก็เป็นแบบเดียวกัน
- จะขยายไปทางไหนตัดสินตอนเริ่มขยาย แล้วไม่เปลี่ยนจนกว่าจะหุบ
- "ขอบจอ" = พื้นที่ที่ใช้ได้จริง **ไม่รวม menu bar และ Dock** ของ**จอที่แคปซูลอยู่** (กรณีต่อหลายจอ)
- ไม่ใช้วิธี "ขยายแล้วเลื่อนการ์ดหนีขอบ" เพราะการ์ดจะขยับหนีเมาส์ เมาส์หลุดออกจากการ์ด แล้วการ์ดจะหุบกับขยายวนไปเรื่อยๆ

**ตำแหน่ง**
- เปิดแอพครั้งแรก: **กลางด้านบน ใต้ menu bar** ของจอหลัก ไม่โดน banner แจ้งเตือนที่ขึ้นมุมขวาบนทับ (prototype ลองแล้วว่ามุมขวาบนโดนทับพอดี)
- **จำตำแหน่ง**ข้ามการเปิดแอพใหม่ ถ้าตำแหน่งที่จำไว้อยู่นอกจอแล้ว (ถอดจอเสริม, เปลี่ยนความละเอียดจอ) ให้กลับไปตำแหน่งเริ่มต้น → ส่งต่อตั๋ว "เก็บข้อมูลของแอพไว้ที่ไหน รูปแบบอะไร"
- ไม่มีโหมดย่อ/ขยายให้กดสลับเอง สถานะย่อกับขยายด้านบนคือโหมดนี้แล้ว

**Light / Dark**
- ทุกหน้าต่างของแอพเปลี่ยนตาม Appearance รวมถึงแคปซูล: Light = กระจกขาว ตัวอักษรเข้ม, Dark = กระจกเทาเข้ม ตัวอักษรขาว
- **Settings มีส่วนใหม่ "Appearance": `System` / `Light` / `Dark`** ค่าเริ่มต้นคือ `System` ถ้าเลือก System แล้วเปลี่ยนโหมดของเครื่อง แอพจะเปลี่ยนตามทันที กด Restore Defaults แล้วกลับไปเป็น System
- ข้อเสียที่ยอมรับ: แคปซูลแบบ Light บนวอลเปเปอร์ที่สีเยอะจะอ่านยากกว่าพื้นดำทึบนิดหน่อย

**Animation ตอนเปลี่ยน Phase**
- แคปซูลหรือการ์ด**เด้งเบาๆ ครั้งเดียว** (ขยายนิดเดียวแล้วกลับ ประมาณ 0.7 วินาที) + **สีค่อยๆ เปลี่ยน**ไปเป็นสีของ Phase ใหม่ ไม่กะพริบซ้ำ (ไม่ได้ใช้แจ้งเตือน ตามตั๋ว "แจ้งเตือนกับเสียงตอนหมดเวลา")
- (agent ตัดสินเอง) ถ้าเครื่องเปิด **Reduce motion** ใน Accessibility จะไม่เด้ง และขยายหรือหุบโดยไม่มี animation

**Settings และ Statistics** (หน้าต่างปกติ มีปุ่มปิดสีแดง ไม่ลอยบนสุด ตามตั๋ว "menu bar กับหน้าต่างลอย")
- สไตล์เดียวกันคือ เนื้อหาจัดเป็น**กล่องมุมโค้งแบบ System Settings** ของ macOS, หัวข้อแต่ละส่วนเป็นตัวเล็กสีเทา, สวิตช์และปุ่มสำคัญเป็น**สีแดงมะเขือเทศ**, ตัวเลขสถิติใช้ SF Rounded
- **Settings** เรียงเป็น Timer → Auto-start → Notifications & Sound → **Appearance** → `Restore Defaults` ชิดขวาล่าง เวลาใช้ช่องตัวเลข + ปุ่มขึ้น/ลง, เสียงใช้ dropdown, บรรทัดเตือนสิทธิ์ notification เป็นสีส้มอยู่ใต้ `Show notifications`
- **Statistics:** การ์ด 3 ใบเรียงแนวนอน, กราฟแท่ง 7 วันในกล่องโค้ง (แท่งของวันนี้สีเข้ม วันอื่นสีอ่อนลง ช่องสุดท้ายเขียนว่า `Today`), ชี้ที่แท่งแล้วเห็น `8 🍅 · 3h 20m`, `Clear History…` ชิดขวาล่าง กล่องยืนยันเลื่อนลงมาจากด้านบนของหน้าต่าง (sheet)

**ทำยากแค่ไหน** (ภาษาคน)
- ส่วนที่ยากที่สุดคือ **ขยายหน้าต่างไปพร้อม animation ให้เนียน** และเลือกทิศที่จะขยายใกล้ขอบจอ ทำได้ด้วย `NSPanel` + SwiftUI ที่ตกลงกันไว้แล้ว บน macOS 14 ไม่ต้องใช้ API ใหม่ ส่วนกระจกโปร่งแสงกับ light/dark ระบบ macOS ทำให้

**ส่งต่อ**
- ตั๋ว "เก็บข้อมูลของแอพไว้ที่ไหน รูปแบบอะไร": Settings เพิ่ม **Appearance** และต้อง**จำตำแหน่งของ Floating Window** (รวมถึงกติกา "อยู่นอกจอแล้วกลับไปตำแหน่งเริ่มต้น")
- ตั๋ว "spec จะสั่ง agent ให้จัดโครงสร้างโค้ดและทดสอบยังไง": เพิ่ม unit test และรายการทดสอบด้วยมือ (เขียนไว้ในตั๋วนั้นแล้ว)
