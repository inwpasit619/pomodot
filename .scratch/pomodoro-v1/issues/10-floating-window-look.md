## Question

**ผู้ใช้อยากได้ UI แบบ modern** — ให้ prototype ช่วยหาว่า "modern" หมายถึงอะไร (เช่น วัสดุโปร่งแสง/blur แบบ macOS, มุมโค้ง, ตัวเลขใหญ่, animation นุ่มๆ) ทำมาให้เลือกหลายแบบ แล้วใช้สไตล์ที่ได้กับ Settings และสถิติด้วย

หน้าต่างลอยควรหน้าตาเป็นยังไง ทำ mock แบบหยาบๆ (HTML ผ่าน `/prototype` ไม่ต้องใช้ Xcode) ให้ผู้ใช้ดูแล้วเลือก

- ขนาด (เล็กแค่ไหน), รูปทรง (แคปซูล / สี่เหลี่ยมมุมมน / วงกลม), ความโปร่งใส
- โชว์อะไรบ้าง: เวลา, ชื่อช่วง (Focus/Break), รอบที่เท่าไหร่, ปุ่มควบคุม (โชว์ตลอดหรือโชว์ตอน hover)
- ช่วง focus กับช่วง break ใช้สีต่างกันไหม
- ตำแหน่งเริ่มต้นบนจอ, ลากย้ายได้และจำตำแหน่งไว้, มีโหมดย่อ/ขยายไหม
- light/dark mode
- (ส่งต่อมาจากตั๋ว "กติกาของ timer") มีวงแหวน/แถบ progress คู่กับ `mm:ss` ไหม, หน้าตาตอน Pause, **Expected finish** ของ Phase และของ Cycle วางตรงไหน และโชว์ตลอดหรือโชว์ตอน hover, ปุ่มบนหน้าต่างลอยมีแค่ ▶︎/⏸, Reset, Skip (ส่วน New Cycle อยู่ในเมนู)
- (ส่งต่อมาจากตั๋ว "menu bar กับหน้าต่างลอย เกี่ยวกันยังไง") มี**ปุ่มซ่อน**บน Floating Window ด้วย (ปิด = ซ่อน ไม่ใช่ออกจากแอพ) ไม่มีปุ่ม Quit, ปุ่มหมุด always-on-top หรือเมนูคลิกขวา ข้อความเป็นภาษาอังกฤษ
- (ส่งต่อมาจากตั๋ว "แจ้งเตือนกับเสียงตอนหมดเวลา ทำงานยังไง") Floating Window ไม่กะพริบเพื่อแจ้งเตือน แต่จะมี animation เล็กๆ ตอนเปลี่ยน Phase ไหม และส่วน Notifications & Sound ใน Settings (สวิตช์ notification, dropdown เสียง 2 ช่อง, บรรทัดเตือนตอนระบบปิดสิทธิ์) ต้องเข้ากับสไตล์ modern ด้วย
- (ส่งต่อมาจากตั๋ว "สถิติ/ประวัติ นับอะไร แสดงยังไง") หน้าต่าง Statistics มีการ์ด 3 ใบ (Today / This Week / All Time), กราฟแท่ง 7 วันล่าสุด และปุ่ม `Clear History…` ให้ทำ mock ด้วยสไตล์ modern ที่เลือก
