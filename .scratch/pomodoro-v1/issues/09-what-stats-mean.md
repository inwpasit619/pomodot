## Question

"สถิติ/ประวัติ" ใน v1 หมายถึงอะไรแน่ๆ

- นับอะไร: จำนวน focus ที่ทำครบ, เวลา focus รวม, focus ที่โดน skip/reset ด้วยไหม (ขึ้นกับกติกาในตั๋ว "กติกาของ timer")
- ดูช่วงไหนได้บ้าง: วันนี้ / 7 วัน / รายสัปดาห์ / ทั้งหมด
- แสดงเป็นตัวเลขเฉยๆ หรือเป็นกราฟ และอยู่ตรงไหน (ในหน้าต่างลอย, เมนูบน menu bar, หรือหน้าต่างแยก)
- นับ "วัน" ตัดตอนเที่ยงคืนตามเวลาเครื่อง ใช่ไหม

ข้อมูลที่มีแล้วจากตั๋ว "กติกาของ timer": Pomodoro = Focus ที่ทำครบเท่านั้น (skip/reset ไม่นับ, pause แล้วทำต่อจนครบนับ) ศัพท์ทั้งหมดอยู่ใน `CONTEXT.md` คำถามที่ยังเหลือคือ Focus ที่ถูก skip/reset ควรเก็บไว้ในประวัติด้วยไหม

(ส่งต่อมาจากตั๋ว "menu bar กับหน้าต่างลอย เกี่ยวกันยังไง") สถิติเป็น**หน้าต่างแยก** เปิดจากเมนู `Statistics…` และหัวเมนูบน menu bar มีบรรทัด `Today: 🍅 5` ต้องตัดสินว่าบรรทัดนี้นับอะไร ตอนตกลงกันใช้สมมติฐานว่า **New Cycle ไม่ลบ Pomodoro ที่บันทึกไว้แล้ว** ต้องยืนยันข้อนี้ด้วย UI เป็นภาษาอังกฤษ

## Answer

(ปิดเมื่อ 2026-10-15 คุยกับผู้ใช้ ศัพท์ **History** เพิ่มไว้ใน `CONTEXT.md`)

**นับอะไร**
- History เก็บแค่ **Pomodoro** (Focus ที่ทำครบ) แต่ละอันมี**เวลาจบ** (เวลาสากล) และ**ความยาว** (นาที) ต้องเก็บความยาวไว้เพราะผู้ใช้เปลี่ยนเวลา Focus ได้ ถ้าไม่เก็บจะคำนวณเวลา Focus รวมไม่ถูก
- บันทึก**ตอนที่ Focus หมดเวลา** ไม่ใช่ตอนกด Start
- Focus ที่โดน skip หรือ reset **ไม่เก็บ** ข้อเสียที่ยอมรับ: ทำอัตราสำเร็จ (completion rate) ไม่ได้ และคำนวณย้อนหลังไม่ได้
- **New Cycle ไม่ลบ History** ปุ่มนี้ล้างแค่ตัวนับของ Cycle

**บรรทัด `Today: 🍅 5` ในเมนู**
- นับจำนวน Pomodoro ของวันนี้อย่างเดียว ไม่มีเวลารวม
- เปลี่ยนเป็น 0 เองตอนเที่ยงคืน ไม่ต้องรอให้เปิดเมนูก่อน

**หน้าต่าง Statistics** (หน้าต่างแยก เปิดจากเมนู `Statistics…` ตามตั๋ว "menu bar กับหน้าต่างลอย เกี่ยวกันยังไง")

```
┌─ Statistics ────────────────────────────┐
│   Today        This Week     All Time   │
│   🍅 5         🍅 23         🍅 412     │
│   2h 05m       9h 35m        171h 40m   │
│                                         │
│   Last 7 Days                           │
│    ▇                                    │
│    ▇     ▇           ▇                  │
│    ▇  ▇  ▇     ▇  ▇  ▇                  │
│   Thu Fri Sat Sun Mon Tue Wed           │
│                                         │
│                       [Clear History…]  │
└─────────────────────────────────────────┘
```

- **การ์ด 3 ใบ:** Today / This Week / All Time แต่ละใบมีจำนวน Pomodoro กับเวลา Focus รวม รูปแบบเวลาคือ `2h 05m` ถ้าไม่ถึงชั่วโมงเป็น `45m`
- **กราฟแท่ง 7 วันล่าสุด** (รวมวันนี้) แท่งละวัน ความสูงคือจำนวน Pomodoro เอาเมาส์ชี้ที่แท่งแล้วเห็นจำนวนกับเวลารวม วันที่ไม่มีก็ยังมีช่องอยู่ แค่ไม่มีแท่ง ใช้ Swift Charts ที่มากับ macOS ไม่ต้องลง library เพิ่ม
- ถ้าเปิดหน้าต่างค้างไว้ ตัวเลขกับกราฟอัปเดตเองทันทีที่ได้ Pomodoro ใหม่ (และตอนข้ามเที่ยงคืน)
- หน้าตาใช้สไตล์ modern เดียวกับที่เลือกในตั๋ว "หน้าตาและตำแหน่งของหน้าต่างลอย"

**ตัดวันกับสัปดาห์**
- วันใหม่เริ่ม**เที่ยงคืนตามเวลาเครื่อง** Pomodoro ที่ข้ามเที่ยงคืนนับเป็น**วันที่จบ**
- สัปดาห์เริ่มวันไหนให้ตามการตั้งค่าของเครื่อง (first weekday ใน Language & Region) แอพไม่มีสวิตช์ของตัวเอง
- เก็บเวลาจริงแบบสากล แล้วตอนแสดงผลแบ่งวันตาม**โซนเวลาปัจจุบัน**ของเครื่อง ถ้าข้ามโซนเวลา บางอันอาจย้ายไปอยู่อีกวัน ข้อนี้ยอมรับได้

**เก็บนานแค่ไหน / ลบ**
- **เก็บตลอดไป** ไม่ลบอัตโนมัติ (วันละ 10 อันติดกัน 10 ปีก็ยังไม่ถึง 2 MB)
- ปุ่ม **`Clear History…`** มุมล่างของหน้าต่าง Statistics กดแล้วมีกล่องยืนยันที่บอกจำนวนที่จะลบ (เช่น "Delete all 412 Pomodoros? This can't be undone.") ถ้า History ว่างอยู่ปุ่มจะกดไม่ได้ กล่องยืนยันต้องขึ้นมาด้านหน้าเสมอเหมือนกล่องของ Reset/New Cycle
- ลบแล้ว**ไม่กระทบ timer** (Phase, ตัวนับ Cycle และเวลาที่เหลือยังอยู่) แต่ `Today` จะกลับเป็น 0

**ไว้หลัง v1 (ไม่ทำใน v1)**
- เลือกช่วงเวลาอื่น (30 วัน, รายเดือน), streak, ดูรายการทีละอัน, ลบบางอันหรือลบเป็นช่วง, export

**ส่งต่อ**
- เก็บ History, สถานะ timer และ Settings เป็นไฟล์แบบไหน ไว้ที่ไหน → ตั๋วใหม่ "เก็บข้อมูลของแอพไว้ที่ไหน รูปแบบอะไร"
- สิ่งที่ต้องมี unit test และอยู่ใน checklist ทดสอบด้วยมือ → เพิ่มลงตั๋ว "spec จะสั่ง agent ให้จัดโครงสร้างโค้ดและทดสอบยังไง"
