# กติกาของ timer: pause, skip, reset, Mac sleep และ auto-start

Type: grilling
Label: wayfinder:grilling
Status: open
Map: [Map: Pomodoro ลอยบนจอ](../map.md)

## Question

timer ควรทำงานยังไงในแต่ละสถานการณ์

- ปุ่มที่มี: start / pause / resume / skip / reset แต่ละปุ่มทำอะไรกับช่วงปัจจุบัน และกับตัวนับรอบ (กี่ focus แล้วถึงจะเป็น long break)
- skip focus ที่ทำไม่ครบ นับเป็น pomodoro ไหม
- Mac sleep / ล็อกจอ / ปิดฝากลางช่วง ควรนับต่อตามเวลาจริง หรือหยุดไว้
- ถ้าเปิด auto-start ไว้ จะเริ่มช่วงถัดไปทันที หรือหน่วงสักแป๊บ และทำไงเมื่อจบ long break (วนรอบใหม่ หรือหยุด)
- แสดงเวลาแบบนับถอยหลัง (mm:ss) หรือเป็นวงแหวน/แถบ progress หรือทั้งสองแบบ
- ปิดแอพกลางช่วงแล้วเปิดใหม่ ควรจำสถานะไว้ไหม
