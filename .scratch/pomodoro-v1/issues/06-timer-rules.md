## Question

timer ควรทำงานยังไงในแต่ละสถานการณ์

- ปุ่มที่มี: start / pause / resume / skip / reset แต่ละปุ่มทำอะไรกับช่วงปัจจุบัน และกับตัวนับรอบ (กี่ focus แล้วถึงจะเป็น long break)
- skip focus ที่ทำไม่ครบ นับเป็น pomodoro ไหม
- Mac sleep / ล็อกจอ / ปิดฝากลางช่วง ควรนับต่อตามเวลาจริง หรือหยุดไว้
- ถ้าเปิด auto-start ไว้ จะเริ่มช่วงถัดไปทันที หรือหน่วงสักแป๊บ และทำไงเมื่อจบ long break (วนรอบใหม่ หรือหยุด)
- แสดงเวลาแบบนับถอยหลัง (mm:ss) หรือเป็นวงแหวน/แถบ progress หรือทั้งสองแบบ
- ปิดแอพกลางช่วงแล้วเปิดใหม่ ควรจำสถานะไว้ไหม

(ใช้ `/domain-modeling` ตกลงศัพท์ให้ตรงกัน เช่น Phase, Cycle, Pomodoro แล้วเขียนลง `CONTEXT.md`)

## Answer

(ปิดเมื่อ 2026-10-15 คุยกับผู้ใช้ ศัพท์ทั้งหมดอยู่ใน `CONTEXT.md`: Phase, Focus, Short Break, Long Break, Pomodoro, Cycle, Expected finish, Skip, Reset, New Cycle)

**ศัพท์**
- **Phase** = การจับเวลาหนึ่งก้อน มี 3 ชนิด: Focus / Short Break / Long Break
- **Pomodoro** = Focus ที่ทำจนครบเท่านั้น ถ้า pause กลางทางแล้วทำต่อจนครบก็ยังนับ แต่ถ้าโดน skip หรือ reset จะไม่นับ
- **Cycle** = Pomodoro N อัน (ค่าเริ่มต้น 4) แล้วจบด้วย Long Break แสดงความคืบหน้าเป็น "2/4" (กำลังทำ Pomodoro ที่ 2)
- ไม่ใช้คำว่า session / round / interval

**ปุ่มและการควบคุม**
- **▶︎/⏸ เป็นปุ่มเดียว:** Pause แล้วเวลาค้างไว้ กด Resume ก็นับต่อจากจุดเดิม
- **Reset** (อยู่บนหน้าต่างลอย) = ให้ Phase ปัจจุบันกลับไปเต็มเวลาแล้วหยุดรอ ใช้เวลาล่าสุดจาก Settings และไม่ไปแตะตัวนับ Cycle
- **New Cycle** (อยู่ในเมนู ไม่อยู่บนหน้าต่างลอย) = กลับไป Focus 1/N แล้วหยุดรอ กดตอน timer เดินอยู่ก็ได้
- **Skip:**

  | skip ตอนอยู่ใน | ไปต่อที่ | ตัวนับ |
  |---|---|---|
  | Focus | Short Break | ไม่ขยับ (เพราะไม่ใช่ Pomodoro) |
  | Short Break | Focus ถัดไป | ไม่ขยับ |
  | Long Break | Focus 1/N ของ Cycle ใหม่ | เริ่มนับใหม่ |

- **ลำดับปกติ:** Focus ครบแล้วตัวนับ +1 ถ้าครบ N จะไป Long Break ถ้ายังไม่ครบไป Short Break จบ Long Break แล้วเริ่ม Cycle ใหม่ที่ Focus 1/N
- **เปิดแอพครั้งแรก:** Focus 1/N เต็มเวลา หยุดรอ

**ล็อกจอ / Sleep**
- ล็อกจอ, จอดับ, screensaver: timer **นับต่อ**
- เครื่อง sleep จริง (ปิดฝา, สั่ง Sleep): **auto-pause** ตื่นมาก็ยังค้างเป็น Pause ต้องกด Resume เอง
- เหตุผล: กัน Focus ที่หมดเวลาตอนเครื่องหลับโดนนับเป็น Pomodoro และไม่ต้องมีกติกาไล่ตามหลาย Phase ที่ผ่านไประหว่างเครื่องหลับ ข้อเสียที่ยอมรับ: ถ้าปิดฝาตอนพักพอดี เวลาพักจะไม่เดิน

**Auto-start**
- มี **2 สวิตช์**: "เริ่ม Break อัตโนมัติ" กับ "เริ่ม Focus อัตโนมัติ" **ค่าเริ่มต้นปิดทั้งคู่**
- เมื่อเปิดไว้ Phase ถัดไปจะเริ่ม**ทันที** ไม่มีหน่วงเวลา
- **จบ Long Break จะหยุดรอเสมอ** ไม่ว่าสวิตช์จะเปิดอยู่หรือไม่ (สวิตช์ Focus มีผลแค่ Short Break → Focus ภายใน Cycle เดียวกัน)
- ถ้าสวิตช์ปิด จบ Phase แล้วจะเตรียม Phase ถัดไปไว้เต็มเวลาแล้วหยุดรอ

**การแสดงเวลา**
- นับถอยหลังเวลาที่เหลือ รูปแบบ `mm:ss` ตลอด ถ้าเกิน 60 นาทีก็แสดงเป็น `90:00` ระหว่าง Pause ต้องมีอะไรบอกว่ากำลัง pause อยู่
- **Expected finish:** ให้ผู้ใช้เห็นทั้ง**เวลาจบของ Phase ปัจจุบัน**และ**เวลาจบของ Cycle** (นับรวม Long Break)
  - คิดจาก **ตอนนี้ + เวลาที่เหลือ** (ส่วนของ Cycle ก็บวกเวลาของทุก Phase ที่ยังเหลือ) โดยสมมติว่าจะไม่มีการหยุดอีก
  - ตอนเดินอยู่ เวลาจบจะนิ่ง ตอน Pause หรือรอให้กด ▶︎ เวลาจบจะเลื่อนออกไปตามเวลาจริง ("ถ้ากดต่อตอนนี้จะเสร็จกี่โมง") ส่วน skip Focus จะทำให้เวลาจบ Cycle เลื่อนออกไป เพราะยังขาด Pomodoro อีกหนึ่งอัน
  - รูปแบบเวลาใช้ตามเครื่อง (12/24 ชม.) ไม่มีวินาที
- ส่งต่อให้ตั๋ว "หน้าตาและตำแหน่งของหน้าต่างลอย": จะมีวงแหวน/แถบ progress ไหม, หน้าตาตอน Pause, Expected finish ทั้งสองค่าวางตรงไหน และโชว์ตลอดหรือโชว์ตอน hover

**ปิดแอพแล้วเปิดใหม่** (quit, รีสตาร์ทเครื่อง)
- จำ Phase, ตัวนับ Cycle และเวลาที่เหลือไว้ เปิดมาจะเป็น **Pause** ช่วงที่ปิดแอพไว้ไม่นับเวลา (หลักเดียวกับตอน sleep)

**เปลี่ยน Settings ระหว่างที่ timer เดิน**
- เปลี่ยนเวลา Focus / Short Break / Long Break: Phase ที่กำลังเดินใช้เวลาเดิมจนจบ แล้ว Phase ถัดไปของชนิดนั้นใช้ค่าใหม่
- เปลี่ยนจำนวน Pomodoro ต่อ Cycle: เริ่มใช้ตอนเข้า Cycle ใหม่
- **ข้อยกเว้น:** Phase ปัจจุบันที่ยังไม่เคยกด Start จะใช้ค่าใหม่ทันที
- อยากใช้ค่าใหม่ทันทีกลางช่วง ให้กด Reset
