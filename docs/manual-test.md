# Pomodot — Checklist ทดสอบด้วยมือ

ทำตามทีละข้อ ผ่านแล้วติ๊ก `[x]` ป้ายท้ายข้อบอกว่ามาจาก milestone ไหน

## Floating Window

- [ ] (M1) **Given** Pomodot ยังไม่ได้เปิดอยู่ **When** เปิดแอพ Pomodot **Then** มีแคปซูลกระจกเล็กๆ ที่มีจุดสีแดง + `25:00` + `READY` อยู่กลางด้านบนของจอหลัก ห่างจากใต้ menu bar นิดเดียว
- [ ] (M1) **Given** เห็นแคปซูลอยู่ **When** เปิด Safari (หรือแอพอื่น) แล้วกดปุ่มสีเขียวมุมซ้ายบนให้เต็มจอ **Then** แคปซูลยังลอยอยู่บนสุดของแอพที่เต็มจอ และยังอ่านตัวเลขบนกระจกได้ชัด
- [ ] (M1) **Given** กำลังพิมพ์อยู่ในแอพอื่น (เช่น Notes) **When** คลิกที่แคปซูลหนึ่งครั้งแล้วพิมพ์ต่อทันที **Then** ตัวอักษรยังไปโผล่ในแอพที่พิมพ์อยู่ และชื่อแอพบนแถบเมนูด้านบนซ้ายยังเป็นแอพนั้น (Pomodot ไม่แย่งไป)
- [ ] (M1) **Given** เห็นแคปซูลอยู่ **When** ปัดสี่นิ้วไปซ้าย/ขวาเพื่อสลับไปอีก Space (หรือเปิด Mission Control แล้วเลือก Space อื่น) **Then** แคปซูลตามไปอยู่ที่เดิมในทุก Space
- [ ] (M1) **Given** แคปซูลลอยอยู่ และเมนูของ Pomodot มีเครื่องหมายถูกหน้า `Always on Top` **When** กด `Always on Top` ในเมนูให้เครื่องหมายถูกหายไป แล้วคลิกหน้าต่างของแอพอื่นที่อยู่ตรงตำแหน่งแคปซูล **Then** แคปซูลไปอยู่หลังหน้าต่างนั้นได้ และเมื่อกด `Always on Top` อีกครั้ง แคปซูลกลับมาลอยบนสุดทันทีโดยไม่ต้องคลิกอะไรเพิ่ม
- [ ] (M1) **Given** เห็นแคปซูลอยู่ **When** เปิดเมนูของ Pomodot แล้วกด `Hide Floating Window` **Then** แคปซูลหายไป และในเมนูคำเดิมเปลี่ยนเป็น `Show Floating Window` กดแล้วแคปซูลกลับมาที่เดิม

## Menu bar

- [ ] (M1) **Given** เปิด Pomodot อยู่ **When** ดูที่ Dock และกด Cmd-Tab ค้างไว้ **Then** ไม่มีไอคอน Pomodot ทั้งใน Dock และในแถบ Cmd-Tab และแถบเมนูด้านบนจอไม่ขึ้นชื่อ Pomodot
- [ ] (M1) **Given** เปิด Pomodot อยู่ **When** ดูที่ menu bar ด้านขวาบน **Then** มีไอคอนนาฬิกาจับเวลา (ยังไม่มีตัวเลขเวลา) ถ้ามองไม่เห็นเพราะไอคอนเยอะจนโดนรอยบากบัง ให้ปิดแอพอื่นบน menu bar บางตัวก่อน
- [ ] (M1) **Given** เห็นไอคอนนาฬิกาบน menu bar **When** คลิกไอคอน **Then** มีเมนูหล่นลงมาและมีคำสั่ง `Quit Pomodot`
- [ ] (M1) **Given** เปิดเมนูของ Pomodot อยู่ **When** กด `Quit Pomodot` **Then** ไอคอนนาฬิกาหายไปจาก menu bar และแอพปิดไป

## Appearance

- [ ] (M1) **Given** เห็นแคปซูลอยู่ **When** เปลี่ยน System Settings › Appearance ระหว่าง Light กับ Dark **Then** Light เป็นกระจกขาวตัวอักษรเข้ม Dark เป็นกระจกเทาเข้มตัวอักษรขาว
- [x] (M1) **Given** เปิด Finder ไปที่โฟลเดอร์ `dist` ในโปรเจกต์ **When** ดูไฟล์ `Pomodot` **Then** ชื่อแสดงเป็น `Pomodot` และไอคอนเป็นแคปซูลสีขาวบนพื้นสีแดงมะเขือเทศ (เงาเป็นรูปทรงธรรมดา ไม่เบลอ) **บอกว่าหน้าตาไอคอนผ่านหรือไม่**
