# Pomodot — Checklist ทดสอบด้วยมือ

ทำตามทีละข้อ ผ่านแล้วติ๊ก `[x]` ป้ายท้ายข้อบอกว่ามาจาก milestone ไหน

## Floating Window

- [x] (M1) **Given** Pomodot ยังไม่ได้เปิดอยู่ **When** เปิดแอพ Pomodot **Then** มีแคปซูลกระจกเล็กๆ ที่มีจุดสีแดง + `25:00` + `READY` อยู่กลางด้านบนของจอหลัก ห่างจากใต้ menu bar นิดเดียว
- [x] (M1) **Given** เห็นแคปซูลอยู่ **When** เปิด Safari (หรือแอพอื่น) แล้วกดปุ่มสีเขียวมุมซ้ายบนให้เต็มจอ **Then** แคปซูลยังลอยอยู่บนสุดของแอพที่เต็มจอ และยังอ่านตัวเลขบนกระจกได้ชัด
- [x] (M1) **Given** กำลังพิมพ์อยู่ในแอพอื่น (เช่น Notes) **When** คลิกที่แคปซูลหนึ่งครั้งแล้วพิมพ์ต่อทันที **Then** ตัวอักษรยังไปโผล่ในแอพที่พิมพ์อยู่ และชื่อแอพบนแถบเมนูด้านบนซ้ายยังเป็นแอพนั้น (Pomodot ไม่แย่งไป)
- [x] (M1) **Given** เห็นแคปซูลอยู่ **When** ปัดสี่นิ้วไปซ้าย/ขวาเพื่อสลับไปอีก Space (หรือเปิด Mission Control แล้วเลือก Space อื่น) **Then** แคปซูลตามไปอยู่ที่เดิมในทุก Space
- [x] (M1) **Given** แคปซูลลอยอยู่ และเมนูของ Pomodot มีเครื่องหมายถูกหน้า `Always on Top` **When** กด `Always on Top` ในเมนูให้เครื่องหมายถูกหายไป แล้วคลิกหน้าต่างของแอพอื่นที่อยู่ตรงตำแหน่งแคปซูล **Then** แคปซูลไปอยู่หลังหน้าต่างนั้นได้ และเมื่อกด `Always on Top` อีกครั้ง แคปซูลกลับมาลอยบนสุดทันทีโดยไม่ต้องคลิกอะไรเพิ่ม
- [x] (M1) **Given** เห็นแคปซูลอยู่ **When** เปิดเมนูของ Pomodot แล้วกด `Hide Floating Window` **Then** แคปซูลหายไป และในเมนูคำเดิมเปลี่ยนเป็น `Show Floating Window` กดแล้วแคปซูลกลับมาที่เดิม
- [ ] (M2) **Given** กำลังพิมพ์อยู่ในแอพอื่น และแคปซูลย่ออยู่ **When** เอาเมาส์ไปวางนิ่งๆ บนแคปซูลแป๊บเดียว (ราว 0.3 วินาที) **Then** แคปซูลค่อยๆ ขยายเป็นการ์ด ตัวแคปซูลไม่ขยับไปไหน (การ์ดงอกออกมาจากตรงนั้น) และแอพที่พิมพ์อยู่ยังเป็นแอพที่ active
- [ ] (M2) **Given** การ์ดขยายอยู่ **When** เอาเมาส์ออกจากการ์ดแล้วรอ **Then** ประมาณครึ่งวินาทีการ์ดค่อยๆ หุบกลับเป็นแคปซูลที่เดิม แต่ถ้าเอาเมาส์ออกแล้วรีบกลับเข้ามาภายในครึ่งวินาที การ์ดไม่หุบ
- [ ] (M2) **Given** แคปซูลย่ออยู่ **When** ลากเมาส์ผ่านแคปซูลเร็วๆ โดยไม่หยุด **Then** แคปซูลไม่ขยาย
- [ ] (M2) **Given** แคปซูลย่ออยู่ **When** คลิกแคปซูลหนึ่งครั้ง **Then** ขยายเป็นการ์ดทันทีโดยไม่ต้องรอ
- [ ] (M2) **Given** แคปซูลย่ออยู่ **When** กดค้างที่แคปซูลแล้วลากไปที่อื่น ปล่อยเมาส์ แล้ววางเมาส์นิ่งๆ บนแคปซูลต่ออีก 2 วินาที **Then** แคปซูลตามเมาส์ไปตลอด ไม่ขยายทั้งระหว่างลากและหลังปล่อย แต่พอเอาเมาส์ออกแล้วกลับมาวางใหม่ แคปซูลขยายตามปกติ
- [ ] (M2) **Given** การ์ดขยายอยู่ **When** กดค้างที่ตัวเลขเวลาตัวใหญ่แล้วลาก จากนั้นลองกดค้างที่ปุ่ม `Start` แล้วลากออกไป **Then** ลากที่ตัวเลขแล้วการ์ดทั้งใบเลื่อนตามโดยไม่หุบ ส่วนกดที่ปุ่ม `Start` แล้วลาก การ์ดไม่ขยับ (และ timer ไม่เริ่มเพราะปล่อยนอกปุ่ม)
- [ ] (M2) **Given** แคปซูลย่ออยู่ **When** ลากแคปซูลไปชนขอบจอทุกด้าน (ขึ้นไปทาง menu bar, ลงไปทาง Dock, ซ้าย, ขวา) **Then** แคปซูลหยุดที่ขอบพื้นที่ใช้งาน ไม่ทับ menu bar ไม่ทับ Dock และไม่หลุดออกนอกจอ
- [ ] (M2) **Given** แคปซูลย่ออยู่ **When** ลากแคปซูลไปชิดขอบล่าง / ขวา (หรือมุมล่างขวา) แล้วชี้ค้างให้ขยาย **Then** การ์ดขยายขึ้นบนและ/หรือไปทางซ้าย ไม่ทะลุจอและไม่ทับ Dock โดยแคปซูลไม่ขยับ
- [ ] (M2) **Given** มีจอเสริมต่ออยู่ **When** ลากแคปซูลข้ามไปจอเสริมแล้วชี้ค้าง **Then** แคปซูลข้ามจอได้ และการ์ดขยายอยู่ในจอเสริมทั้งใบ (ถ้าไม่มีจอเสริมข้ามข้อนี้)
- [ ] (M2) **Given** การ์ดขยายอยู่ **When** ดูของบนการ์ด **Then** มีป้าย `Focus` สีแดง, จุดเล็กๆ 4 จุด + `1/4`, ปุ่มกากบาทมุมขวาบน, เวลาตัวใหญ่ + `READY`, แถบสีแดง และปุ่ม `Start` สีแดง + ปุ่มลูกศรวน (Reset) + ปุ่มข้าม (Skip) เท่านั้น ไม่มีปุ่ม New Cycle, Quit, หมุด และคลิกขวาแล้วไม่มีเมนู
- [ ] (M2) **Given** กำลังพิมพ์อยู่ในแอพอื่น และการ์ดขยายอยู่ **When** กดปุ่ม `Start` บนการ์ดหนึ่งครั้ง **Then** timer เริ่มเดินทันที (ไม่ต้องคลิกสองครั้ง) ปุ่มเปลี่ยนเป็น `Pause` และแอพที่พิมพ์อยู่ยังเป็นแอพที่ active
- [ ] (M2) **Given** Focus กำลังเดินและการ์ดขยายอยู่ **When** กดปุ่มลูกศรวน (Reset) บนการ์ด **Then** กล่อง `Reset this Focus?` เดียวกับในเมนูขึ้นมาด้านหน้า กด `Cancel` แล้วเวลายังเดินต่อ
- [ ] (M2) **Given** การ์ดขยายอยู่ **When** กดปุ่มกากบาทมุมขวาบน **Then** Floating Window หายไป และในเมนูขึ้นเป็น `Show Floating Window` กดแล้วกลับมาเป็นแคปซูลที่เดิม
- [ ] (M2) **Given** Focus กำลังเดิน **When** กด `Pause` แล้วดูตัวเลขบนแคปซูลและบนการ์ดสัก 5 วินาที **Then** ตัวเลขค่อยๆ จางลงแล้วเข้มขึ้นวนไปเหมือนหายใจ และมีคำว่า `PAUSED`
- [ ] (M2) **Given** การ์ดขยายอยู่ที่ Focus **When** กดปุ่มข้าม (Skip) **Then** การ์ดเด้งขยายนิดเดียวแล้วกลับครั้งเดียว สีแดงค่อยๆ เปลี่ยนเป็นสีเขียวของ Short Break ไม่กะพริบซ้ำ และตัวหนังสือเปลี่ยนเป็น `Short Break` ทันทีโดยไม่ซ้อนกัน
- [ ] (M2) **Given** ซ่อน Floating Window ไว้ และ Focus กำลังเดิน **When** ปล่อยให้ Focus หมดเวลา (หรือกด `Skip` ในเมนู) **Then** Floating Window ไม่โผล่กลับมาเอง
- [ ] (M2) **Given** เปิด System Settings › Accessibility › Display › Reduce motion **When** ชี้ค้างให้การ์ดขยาย, เอาเมาส์ออกให้หุบ, กด `Pause` และกด Skip **Then** การ์ดขยายและหุบทันทีโดยไม่มี animation, ไม่เด้ง, ตัวเลขไม่หายใจ (ปิด Reduce motion กลับหลังทดสอบ)
- [ ] (M2) **Given** แคปซูลขึ้น `25:00` + `READY` **When** กด `Start` ในเมนู แล้วกด `Pause` **Then** ตอนเดินคำว่า `READY` หายไป ตัวเลขนับถอยหลัง และจุดสีแดงเรืองแสงเบาๆ ตอน Pause ขึ้นคำว่า `PAUSED` และตัวเลขหยุดนิ่ง

## Menu bar

- [x] (M1) **Given** เปิด Pomodot อยู่ **When** ดูที่ Dock และกด Cmd-Tab ค้างไว้ **Then** ไม่มีไอคอน Pomodot ทั้งใน Dock และในแถบ Cmd-Tab และแถบเมนูด้านบนจอไม่ขึ้นชื่อ Pomodot
- [x] (M1) **Given** เปิด Pomodot อยู่ **When** ดูที่ menu bar ด้านขวาบน **Then** มีไอคอนนาฬิกาจับเวลา (ยังไม่มีตัวเลขเวลา) ถ้ามองไม่เห็นเพราะไอคอนเยอะจนโดนรอยบากบัง ให้ปิดแอพอื่นบน menu bar บางตัวก่อน
- [x] (M1) **Given** เห็นไอคอนนาฬิกาบน menu bar **When** คลิกไอคอน **Then** มีเมนูหล่นลงมาและมีคำสั่ง `Quit Pomodot`
- [x] (M1) **Given** เปิดเมนูของ Pomodot อยู่ **When** กด `Quit Pomodot` **Then** ไอคอนนาฬิกาหายไปจาก menu bar และแอพปิดไป
- [ ] (M2) **Given** System Settings › Appearance เป็น Light และ Pomodot เพิ่งเปิด (Focus ยังไม่เริ่ม) **When** ดูที่ menu bar, กด `Start` ในเมนู, กด `Pause`, แล้วกด `Resume` **Then** ตอนยังไม่เริ่มเห็นแค่ไอคอนนาฬิกาจับเวลาไม่มีตัวเลข, ตอนเดินเห็นไอคอนนาฬิกาจับเวลา + เวลานับถอยหลัง, ตอน Pause เห็นไอคอนวงกลมมีขีดหยุดสองขีด + เวลาที่สีจางลง, และไอคอนกับตัวเลขเป็นสีเดียวกับไอคอนอื่นบน menu bar (เช่น Wi‑Fi)
- [ ] (M2) **Given** ทำข้อบนเสร็จแล้ว **When** เปลี่ยน Appearance เป็น Dark แล้วดูทั้งตอนเดินและตอน Pause อีกครั้ง **Then** ไอคอนและตัวเลขเปลี่ยนสีตาม menu bar อ่านออกชัด และตอน Pause ตัวเลขยังจางกว่าตอนเดิน
- [ ] (M2) **Given** Focus กำลังเดินอยู่ **When** จ้องเวลาบน menu bar และบนแคปซูลสัก 15 วินาที **Then** ตัวเลขลดลงทีละวินาทีไม่ข้าม และตัวเลขไม่ขยับซ้ายขวา (ไอคอนข้างๆ ไม่กระตุก)
- [ ] (M2) **Given** Focus กำลังเดินอยู่ **When** เปิดเมนูของ Pomodot ค้างไว้สัก 5 วินาที **Then** เวลาบน menu bar และบนแคปซูลยังเดินต่อระหว่างที่เมนูเปิดอยู่
- [ ] (M2) **Given** Focus กำลังเดินอยู่ จำเวลาที่เหลือไว้ **When** ล็อกจอ (Control-Command-Q) รอ 1 นาทีแล้วปลดล็อก **Then** timer ยังเดินอยู่ (ไม่ได้ Pause) และเวลาที่เหลือลดลงประมาณ 1 นาที
- [ ] (M2) **Given** Focus กำลังเดินอยู่ **When** ปิดฝาเครื่อง (หรือเมนู Apple › Sleep) รอ 1 นาทีแล้วเปิดเครื่องกลับมา **Then** Pomodot เป็น Pause (`PAUSED` บนแคปซูล, ไอคอน Pause บน menu bar) เวลาที่เหลือเท่ากับตอนก่อนหลับ ไม่ลดลง และในเมนูขึ้นคำว่า `Resume`
- [ ] (M2) **Given** เปิดเมนูของ Pomodot **When** ดูรายการบนสุด **Then** เรียงเป็น `Start` (หรือ `Pause` / `Resume`), `Skip`, `Reset…`, `New Cycle…` แล้วค่อยเป็นเส้นคั่น
- [ ] (M2) **Given** Focus 1/4 กำลังเดินอยู่ **When** กด `Skip` ในเมนู **Then** แคปซูลเปลี่ยนเป็นจุดสีเขียว + `05:00` + `READY` ทันที ไม่มีกล่องถาม ไม่มีเสียง และเมื่อกด `Skip` อีกครั้งกลับมาเป็นจุดสีแดง + `25:00` + `READY` (ยังเป็น Focus ที่ 1 เพราะ Focus ที่โดน Skip ไม่นับ)
- [ ] (M2) **Given** แคปซูลขึ้น `25:00` + `READY` (ยังไม่เริ่ม) **When** กด `Reset…` แล้วกด `New Cycle…` ในเมนู **Then** ไม่มีกล่องถามขึ้นเลย เพราะยังไม่มีอะไรจะหาย
- [ ] (M2) **Given** Focus กำลังเดินอยู่ และคุณกำลังพิมพ์อยู่ในแอพอื่น (เช่น Notes) **When** กด `Reset…` ในเมนูของ Pomodot **Then** กล่อง `Reset this Focus?` ที่บอกว่า `It will go back to 25:00. It won't count as a Pomodoro.` ขึ้นมาอยู่ด้านหน้าสุด ไม่ได้ไปซ่อนอยู่หลังแอพที่พิมพ์อยู่ กด `Cancel` แล้วเวลายังเดินต่อจากเดิม กด `Reset…` อีกครั้งแล้วกด `Reset` แคปซูลกลับเป็น `25:00` + `READY`
- [ ] (M2) **Given** Focus กำลังเดินอยู่ และคุณกำลังพิมพ์อยู่ในแอพอื่น **When** กด `New Cycle…` ในเมนู **Then** กล่อง `Start a new Cycle?` ที่บอกว่า `Progress in this Cycle will be cleared. Your History is kept.` ขึ้นมาอยู่ด้านหน้าสุด กด `New Cycle` แล้วแคปซูลกลับเป็นจุดสีแดง + `25:00` + `READY`
- [ ] (M2) **Given** Focus กำลังเดินอยู่ **When** ปล่อยให้เดินจนหมดเวลา (หรือรอดู Short Break ที่ต่อจากกัน) **Then** แคปซูลเปลี่ยนเป็นจุดสีเขียว + `05:00` + `READY` และไอคอนบน menu bar เป็นรูปถ้วยกาแฟบนจานรองโดยไม่มีตัวเลข

## Appearance

- [x] (M1) **Given** เห็นแคปซูลอยู่ **When** เปลี่ยน System Settings › Appearance ระหว่าง Light กับ Dark **Then** Light เป็นกระจกขาวตัวอักษรเข้ม Dark เป็นกระจกเทาเข้มตัวอักษรขาว
- [x] (M1) **Given** เปิด Finder ไปที่โฟลเดอร์ `dist` ในโปรเจกต์ **When** ดูไฟล์ `Pomodot` **Then** ชื่อแสดงเป็น `Pomodot` และไอคอนเป็นแคปซูลสีขาวบนพื้นสีแดงมะเขือเทศ (เงาเป็นรูปทรงธรรมดา ไม่เบลอ) **บอกว่าหน้าตาไอคอนผ่านหรือไม่**
